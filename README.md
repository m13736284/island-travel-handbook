# 远方志（Island Travel Handbook）

一个面向旅行者的开源网站原型：既能浏览国家与目的地攻略，也能根据自己的偏好生成旅行草案。

## 现在可以体验什么

- 浏览 6 个示例目的地：巴厘岛、日本关西、冰岛、意大利、泰国、葡萄牙
- 按「海岛度假 / 亚洲 / 欧洲 / 自然风光」筛选攻略
- 搜索目的地，并跳转到旅行定制区
- 填写目的地、出发日期、天数、旅行方式和预算
- 生成一份个性化旅行草案

## 如何查看

下载本仓库后，双击 `index.html`，即可在浏览器中打开，无需安装软件。

## 产品目标

```
浏览公开旅行攻略
        ↓
填写个人旅行需求
        ↓
AI 调研真实信息并生成专属手册
        ↓
用户保存、调整与分享
```

## 下一步开发

1. 为每个国家建立完整攻略页（景点、住宿、餐厅、交通、预算、签证等）
2. 接入 AI 生成，让「制作我的旅行」产出完整的按日行程
3. 加入保存、分享和二次调整功能
4. 部署成公开网址，让所有人直接使用
